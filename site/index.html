Como trabalho

01

SaaS ponta-a-ponta

Arquitetura, backend, frontend e deploy. Não terceirizo o que importa — entrego a stack completa, do schema ao componente.

02

Multi-tenant em produção

Isolamento por schema no PostgreSQL, módulos desacoplados em Laravel, sem vazar dado entre clientes. Padrão consistente em vários produtos.

03

IA aplicada ao produto

Agentes via MCP rodando dentro do produto, não chatbot grudado por fora. Operam dados reais, com permissão real, sob o mesmo modelo de tenant.

Sobre

Engenheira de software com foco em plataformas SaaS de domínio complexo. Trabalho com a stack Laravel + Vue 3 + PostgreSQL multi-tenant em produtos rodando em produção nos setores público, municipal e de RH/folha.

Nos últimos anos consolidei projetos heterogêneos em uma plataforma técnica coerente — mesma arquitetura modular, mesmo modelo de isolamento por tenant, mesmos padrões de qualidade. Isso me permite entregar features novas em qualquer um deles na metade do tempo.

Estou explorando agentes de IA integrados ao produto via MCP — não como camada de marketing, mas como interface real de operação.
