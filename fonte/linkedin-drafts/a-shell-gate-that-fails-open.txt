A rule written in CLAUDE.md is a suggestion. A PreToolUse hook is not.

I built a gate that runs before every Bash command in Claude Code and blocks force pushes, destructive DDL, writes to .env, among others — always returning a reason and a hint for the agent, not just a "no."

Testing my own README before publishing, I found a real bug: on a path with a space in it, the gate failed silently and let the command through. The test suite never caught it, because it tested the function directly and never exercised the CLI entry point.

The tests also record what the gate doesn't catch — two known evasions are marked skip, not deleted.

Full article, with code: https://saracgpereira.com/writing/a-shell-gate-that-fails-open/
