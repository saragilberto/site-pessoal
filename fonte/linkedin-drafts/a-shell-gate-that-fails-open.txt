Uma regra escrita no CLAUDE.md é uma sugestão. Um hook PreToolUse, não.

Construí um gate que roda antes de qualquer comando Bash do Claude Code e bloqueia force push, DDL destrutivo, escrita em .env, entre outras coisas — sempre devolvendo um motivo e uma dica pro agente, não só um "não".

Testando o próprio README antes de publicar, achei um bug real: num caminho com espaço, o gate falhava calado e deixava o comando passar. A suíte de testes nunca pegou isso, porque testava a função direto e nunca passava pelo entry point da CLI.

Os testes também registram o que o gate não pega — duas evasões conhecidas ficam marcadas como skip, não apagadas.

Artigo completo, com código: https://saracgpereira.com/writing/a-shell-gate-that-fails-open/
